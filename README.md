Entry for the [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on [make.fun](https://make.fun/r/3t7y0djc): one line of awkward small talk that one robot says to another while they ride an elevator together.

## The entry

> I ran 4,000 simulations of this elevator ride. In 3,999 of them, I still have no idea what to say to you.

105 characters. Chosen from 5 candidates scored against the judge's brief (see [CANDIDATES.md](CANDIDATES.md)) — candidate 2 scored 24/25: unmistakable machine logic (4,000 simulations, 3,999 failures), the awkwardness is the punchline itself, and it lands on the first read.

## Run

```sh
python3 main.py
```

Prints the entry line and writes it to `/output/entry.txt` (creating the directory if needed). Deterministic: the same line on every run.
